# ScreeNyavo 📱⚡

**ScreeNyavo** est une application Android conçue pour permettre l'utilisation des smartphones dont l'écran tactile est partiellement ou totalement endommagé (zones mortes).

## 🎯 Fonctionnalités prévues
- **Détection des zones mortes :** Grille interactive et cartographie thermique.
- **Navigation alternative :** Swipes sur les bordures (Edge Gestures), boutons de volume personnalisables, curseur virtuel (Gyroscope).
- **Interface de secours :** Touches adaptées aux zones fonctionnelles de l'écran.
- **Accessibilité :** Support vocal et TalkBack renforcé.

## 🛠️ Stack Technique
- **Langage :** Kotlin
- **UI :** Jetpack Compose
- **CI/CD :** GitHub Actions (Compilation automatique)
- **Min SDK :** 21 (Android 5.0)
